# מפרט בקרת גישה — גרסה 2

**סוג מסמך:** דמו עברי ל־SpecLens  
**מטרה:** חילוץ דרישות, צ׳אט מצוטט, והשוואת גרסאות בעברית  

---

## 1. מטרה

מסמך זה מגדיר דרישות לבקרת גישה למערכת ניהול מפרטים.

## 2. דרישות פונקציונליות

1. המערכת **חייבת** לאמת משתמש מול מפתח גישה למרחב העבודה לפני כל פעולת קריאה או כתיבה.
2. המערכת **חייבת** לדחות בקשות ללא אימות עם קוד HTTP 401.
3. המערכת **חייבת** לרשום אירוע ביקורת לכל העלאת מסמך **ולכל מחיקת מסמך**.
4. המערכת **מומלצת** להציג הודעות שגיאה בעברית כאשר שפת הממשק היא עברית.
5. המערכת **חייבת** לאפשר למשתמש לבחור שפת ממשק אנגלית או עברית.

## 3. אבטחה

1. **אסור** לאחסן מפתחות גישה בטקסט גלוי בלוגים.
2. המערכת **חייבת** להגביל קצב בקשות ל־60 בקשות לדקה לכל מפתח.
3. המערכת **חייבת** לתמוך ב־RTL בממשק כאשר נבחרה עברית.

## 4. הערות

גרסה 2 מחמירה את מגבלת הקצב, מוסיפה ביקורת למחיקות, ודורשת בחירת שפה ו־RTL.
